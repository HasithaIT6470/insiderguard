# InsiderGuard demo seed readme

This file is generated by `backend/app/seed_demo.py` when the demo database is
seeded. Run the command from `backend/` to replace this readme with the
credentials, case numbers, metrics, persona stories and walkthrough for the
actual run:

```powershell
./.venv/Scripts/python.exe -m app.seed_demo --reset
```

## Demo accounts

| Login | Password | Role |
|---|---|---|
| `admin` | `Guard#12345` | Administrator |
| `analyst` | `Review#12345` | Analyst |
| `analyst2` | `DemoReview#23456` | Analyst |
| `analyst3` | `DemoReview#34567` | Analyst |

The `admin` and `analyst` credentials can be changed with
`INSIDERGUARD_ADMIN_USER`, `INSIDERGUARD_ADMIN_PASSWORD`,
`INSIDERGUARD_ANALYST_USER` and `INSIDERGUARD_ANALYST_PASSWORD`. The generated
file contains the actual account names and passwords used for that seed run.

Use [DEMO_GUIDE.md](DEMO_GUIDE.md) for the complete generated walkthrough.
